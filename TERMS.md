# Key Terms
### Agent: 
An autonomous system that perceives its environment through sensors and acts upon that environment to achieve specific goals.

### Routing: 
The process of directing user queries to the most appropriate specialized agent based on query content and context.

### Memory:
Storage mechanism that allows agents to maintain context and state across multiple interactions.

### TF-IDF:
Term Frequency-Inverse Document Frequency, a numerical statistic that reflects word importance in a document collection.

### Cosine Similarity:
A metric used to measure how similar two vectors are, commonly used for text similarity comparisons.

### Semantic Matching:
Finding the meaning-based similarity between texts, rather than exact keyword matches.
